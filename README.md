# Sudoku Crush VN — Google Play policy pages

Static pages prepared for Google Play Console:

- `privacy-policy.html` — Privacy Policy URL
- `delete-account.html` — Delete Account & Data URL
- `index.html` — landing page

## Before publishing

1. Replace the support-email wording with the actual support email used on the Google Play listing, if desired.
2. Publish this folder at a public HTTPS URL, for example GitHub Pages.
3. Verify both pages in an incognito browser window.
4. In Google Play Console use:
   - Privacy policy URL: `https://<account>.github.io/<repo>/privacy-policy.html`
   - Delete account URL: `https://<account>.github.io/<repo>/delete-account.html`

Do not enter example or placeholder URLs into Play Console.
